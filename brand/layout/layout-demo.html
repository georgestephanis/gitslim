▍ implementation notes

VIEWPORT
Build for a min terminal width of 80 cols. Above that, columns flex. The reference renders at 1280×640 (≈ 110 cols, 36 rows at 12pt).
ROW STATES
  • [ ] idle — ink-mute
  • [x] marked — magenta + magenta size
  • focused — cyan bar at left, 8% cyan bg, path tint cyan
SIZE COLOR
Below 100 M → ink-dim. 100 M – 1 G → ink. ≥ 1 G → amber. When the row is marked, the size flips to magenta regardless of size.
KEY HINTS
Glyph is colored by intent: cyan for navigation, magenta for destructive (S, Y), ink-dim for neutral (Q, ESC). Label is always ink-mute.
CRT FX
Optional and subtle. Scanlines at 3 px repeat with 2.5 % opacity overlay-blended. Vignette is a radial mask transparent→55 % black past 50 % radius. Disable on low-end terminals.
FONT
Use the user's terminal font (don't impose). The reference uses JetBrains Mono. For figlet splashes, prefer the included ASCII medium-01 sigil (fits in 80 cols).
